# Airbnb listing keyword sync

Keep the Airbnb listing and lakearrowheadaframe.com saying the same true things so brand search, Marketplace, and organic reinforce each other.

## Recommended title pattern

Lead with the searchable product, then proof:

`Lake Arrowhead A-Frame · Sauna, Hot Tub, Dog-Friendly Yard`

Avoid promising beach clubs or a generic “lake pass.”

## Description blocks to mirror the site

1. **Opening:** Renovated A-frame in Arrowhead Woods, ~90 minutes from Los Angeles / ~5 minutes to the Village.
2. **Ritual:** Indoor sauna → cool pine air → hot tub under the trees.
3. **Dogs:** Dog-friendly with fenced yard — declare pets at booking.
4. **Lake honesty:** Owner lake trails / shoreline when registered for eligible STR stays; beach clubs not included.
5. **Proof:** Guest Favorite, rating, Superhost, STR permit number.

## Site URLs to put in the Airbnb guidebook

- Homepage: https://lakearrowheadaframe.com/
- Shoreline decoder: https://lakearrowheadaframe.com/shoreline-rights
- Weekend from LA: https://lakearrowheadaframe.com/weekend-from-los-angeles

## Do not

- Copy sale-site “for sale / investment” language into the guest listing
- Use “lake pass included” as shorthand for beach clubs
- Change rating/review counts on the website without updating Airbnb-synced numbers in `cabin.ts`
