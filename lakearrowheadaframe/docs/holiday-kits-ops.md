# Holiday Ready Kits. Ops

Paid per-stay kits for the Lake Arrowhead A-Frame. Stay books on Airbnb; kit is requested after booking and staged before check-in.

## Payment flow

1. Guest books on Airbnb.
2. Send **Saved Reply** for the matching kit (or link [Holiday Ready](https://lakearrowheadaframe.com/holiday-ready)).
3. Guest confirms kit + stay dates.
4. Send Airbnb **Special Offer / alteration** for the kit price (preferred). Venmo only as fallback. Note reservation code in the memo.
5. After payment clears, stage kit the day before check-in (or morning of for same-day turnovers).
6. After checkout: teardown, restock consumables, return durables to labeled tote.

## Cutoff rules

| Kit | Request cutoff |
|---|---|
| Default (all kits except Valentine’s) | **5 days** before check-in |
| Valentine Reset | **3 days** before check-in (perishables) |

If a guest requests after cutoff: politely decline, or offer a reduced “consumables only” drop if you already have stock on hand. Never rush a full stage.

## Same-day double-kit rule

Back-to-back holiday guests who both buy: reuse durable decor; refresh consumables only. Do not restage the tree/table from scratch unless the prior guest damaged something.

## Airbnb Saved Replies

### Master. After any booking in a kit window

```
Holiday Ready kits

Want the cabin to show up already dressed for the holiday? We offer optional paid kits (tree, table for 8, cocoa bar, etc.) staged before you arrive.

Details + prices: https://lakearrowheadaframe.com/holiday-ready

Reply with the kit name if you’d like one. I’ll add it to your reservation as a Special Offer. Please request at least 5 days before check-in (3 days for Valentine’s).
```

### Kit confirm (example. Christmas)

```
Christmas Ready. $249

Includes: pre-lit tree + ornaments, stockings, garland, cocoa bar (mixes, mugs, marshmallows), throw blankets, fireplace staging.

Does not include: real trees, cooked meals, or mid-stay restocking.

I’ll send a Special Offer on this reservation for $249. Once you accept, we’ll stage everything before your check-in on [DATE].
```

Use the same pattern for other kits; pull includes/excludes from the site or `src/data/holiday-kits.ts`.
